# 『優しい人の、優しくない恋』Webノベルゲーム

小説『優しい人の、優しくない恋』の公式アセットと名シーン原稿をもとに構築されたインタラクティブ・ビジュアルノベルゲームです。

## 収録エピソード
- **Episode 4.5: 深夜23時の会議室 —「火を持って帰る日」**
  - 花園瑞希が一人残業してプロンプト検証を続ける深夜、通りかかった笹塚怜が彼女を止めに入る重要シーン。
  - 「君の火を消したいわけじゃない。今日は火を持って帰る日」「君の代わりに答えるためじゃない。君が自分で答えるための準備を、隣でするだけ」という作品の核心テーマが描かれます。

## 機能
- **美麗ビジュアル＆立ち絵アニメーション**: 公式立ち絵（笹塚怜）およびヒロインアイコン（花園瑞希）の表示
- **マルチエンディング分岐**: 瑞希の選択肢によって「怜との共鳴度（好感度）」が変動し、エピローグ評価が分岐
- **Web Audio SE演出**: セリフ送り音・選択音・UIフィードバック音（オン/オフ切り替え可能）
- **バックログ機能（LOG）**: 会話履歴をいつでも確認可能
- **オートプレイ機能（AUTO）**: 自動セリフ送り
